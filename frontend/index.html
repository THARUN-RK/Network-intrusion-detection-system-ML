📖 Cybersecurity & Machine Learning Glossary
Key terminology explained in plain English for examiners, educators, and recruiters.
1. Network Flow
A sequence of network packets between two devices sharing the same source/destination IPs, ports, and protocol during a conversation.
2. SVM (Support Vector Machine)
A supervised machine learning model that finds an optimal mathematical boundary to distinguish safe traffic from cyberattacks.
3. RBF Kernel
Radial Basis Function — a mathematical tool that projects complex network behaviors into higher dimensions where attack patterns become clearly separable.
4. CIC-IDS2017
A standard cybersecurity benchmark dataset containing realistic network conversations and diverse attack scenarios recorded over 5 days.
5. DDoS Attack
Distributed Denial of Service — an attack where many compromised machines flood a server simultaneously to take it offline.
6. Port Scan
A reconnaissance tactic where an attacker probes multiple network ports to find open entryways and vulnerable services.
7. Model Confidence
The statistical probability (0% to 100%) that the machine learning algorithm assigns to its classification decision.
8. Reputation Score
A trust rating (0–100) for an IP address that drops during attacks and slowly recovers over time as clean traffic is observed.
9. Firewall Block
A defensive security action that automatically rejects all incoming network packets from an untrusted or malicious IP address.
10. False Positive
When normal, legitimate network traffic is accidentally flagged by the security system as a malicious cyberattack.
