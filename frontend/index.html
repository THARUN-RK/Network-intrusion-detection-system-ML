🎯 IP-Based Network Attack Analyzer
Search available network traffic records for an entered source IP, extract authentic 71-feature vectors, and run the trained multiclass RBF SVM model to identify observed network attacks (BENIGN, DoS, DDoS, PortScan, Brute Force, etc.).
ℹ️ Observed Network Traffic Classifier vs. Threat Intelligence Reputation
Empirical Traffic Analysis: This engine evaluates genuine recorded network session flows associated with an IP. The trained multiclass RBF SVM inspects 71 statistical traffic features (packet lengths, inter-arrival times, window sizes, flags). The IP string itself is never used as an ML input feature, preserving strict scientific integrity. This is completely distinct from external threat intelligence reputation scores (VirusTotal / AbuseIPDB), which reflect external third-party reports.

🧠 Model Architecture & Hyperparameters
Trained on Canadian Institute for Cybersecurity CIC-IDS2017 benchmark dataset.
Algorithm
Support Vector Classifier (SVC) with Radial Basis Function (RBF) kernel.
Hyperparameters
C = 10.0, gamma = 'scale', probability = True, random_state = 42.
Feature Pipeline
71 statistical features normalized via StandardScaler in scikit-learn Pipeline.
Multiclass Strategy

⚙️ Engineering Architecture & Specifications
System hardware specifications, optimization notes, and dual-engine pipeline breakdown.
Hardware Platform
Intel Core i3-1215U (6 cores / 8 threads), 8 GB RAM, Windows 11 / Render Linux Cloud Container.
Resource Optimization
Single worker Uvicorn setup, non-blocking asyncio event loop, <140 MB memory footprint (within Render 512MB limit).
Multi-Database Engine
SQLite for local development (/tmp fallback) and automatic PostgreSQL connection pool support.
Threat Intelligence Cache
In-memory LRU threat cache with 24-hour TTL preventing API quota exhaustion.
