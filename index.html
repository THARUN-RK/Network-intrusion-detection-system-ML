System Architecture

🧠 Multiclass SVM (RBF Kernel)

Trained with class-balanced sample weights and 3-fold stratified cross-validation. Non-linear decision surfaces generalize against polymorphic and zero-day attacks.

⚡ FastAPI REST Microservice

High-throughput asynchronous API endpoints for real-time single flow triage and high-volume CSV batch prediction with Pydantic validation.

🛡️ Streamlit SOC Dashboard

Dark cybersecurity operations center dashboard featuring live threat feeds, interactive Plotly distribution charts, and downloadable incident reports.

🔍 Leakage-Free Preprocessing

Eliminates topological identifiers (IP addresses, Port IDs, Flow IDs, Timestamps) to prevent artificial model overfitting and ensure authentic field generalization.

📜 SQLite Security Audit Log

Parameterized historical database recording prediction timestamps, confidence ratings, and automated security incident alerts.

📡 Scapy Live Flow Capture

Real-time packet capture extension that tracks bidirectional TCP/UDP streams and transforms raw packets into the exact 71-feature model schema.
