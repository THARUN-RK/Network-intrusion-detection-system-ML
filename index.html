System Design
⚙️ SOC Architecture
End-to-end pipeline from raw packet capture to real-time threat classification and incident response.
🧠

Multiclass SVM (RBF Kernel)

Trained with class-balanced sample weights and 3-fold stratified cross-validation. Non-linear decision surfaces generalize against polymorphic and zero-day attacks. C=10, gamma=scale.

⚡

FastAPI REST Microservice

High-throughput asynchronous API endpoints for real-time single flow triage and high-volume CSV batch prediction with Pydantic validation and JWT authentication.

🛡️

Streamlit SOC Dashboard

8-page interactive Security Operations Center with threat analytics, IP monitoring, incident investigation, model performance evaluation, and PDF/CSV audit reports.

📡

Scapy Packet Capture

Bidirectional TCP/UDP stream reassembly maps raw packets to 71-feature CIC-IDS2017 flow schema for real-time SVM classification.

🗄️

Multi-Database Support

SQLite for development, PostgreSQL for production. Stores predictions, alerts, incidents, IP reputation profiles, and audit trails via SQLAlchemy ORM.

🐳

Docker & Cloud Deployment

Containerized with Docker Compose. Deployed on Render with automatic model training, database initialization, and concurrent FastAPI + Streamlit startup.
